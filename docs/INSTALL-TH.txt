วิธีติดตั้ง
สำคัญ: อย่าลืมตั้งภาษาในเกมเป็น English (ENG) และเปิด Subtitles เพื่ออ่านซับบทพูด
1. แตก ZIP ทั้งชุดลงโฟลเดอร์ใหม่
2. ปิดเกม แล้วเปิด UBW-Thai-Setup.exe
3. ตรวจตำแหน่งเกม หรือกด “เลือกเกม…” แล้วเลือกโฟลเดอร์หลัก เช่น
   N:\SteamLibrary\steamapps\common\StarshipTroopers_UltimateBugWar
   หรือ C:\Program Files (x86)\Steam\steamapps\common\StarshipTroopers_UltimateBugWar
   เลือกโฟลเดอร์เกม ไม่ต้องเลือกไฟล์ .exe หรือโฟลเดอร์ Content/Paks
   หาโฟลเดอร์ได้ใน Steam: คลิกขวาที่เกม > Manage > Browse local files
4. กด “ติดตั้ง / อัปเดตภาษาไทย” รอจนแจ้งสำเร็จ
5. เปิดเกม ใช้ภาษา English (ENG) และเปิด Subtitles

สิ่งที่ตั้งใจคงภาษาอังกฤษ
ชื่อคน อาวุธ ศัตรู การสนับสนุน ชื่อปฏิบัติการ/บางชื่อภารกิจ
เมนูและหน้าตั้งค่าส่วนใหญ่ ชื่อปุ่มจริงบนอุปกรณ์ รายชื่อผู้สร้าง และประกาศสิทธิ์ของเกม
ไม่ได้แปลเสียงพากย์ ป้ายที่ฝังอยู่ในภาพ หรือข้อความนอกตารางภาษาที่ตรวจพบ

HUD และซับ
HUD Scaling ปรับขนาด HUD ทั้งชุด; Safe Zone ปรับระยะจากขอบจอ
รุ่นนี้คงระยะบรรทัด/แนวฐานฟอนต์ต้นฉบับเพื่อลดข้อความชนกรอบ
ยังไม่มีตัวเลือกขยายเฉพาะซับในตัวติดตั้ง ไม่รับรองว่า HUD Scaling จะขยายซับทุกชนิด

สถานะการตรวจ
ผู้ใช้ทดสอบใช้งานในเกมและยืนยันว่าใช้ได้แล้ว
ผ่านการตรวจโครงสร้างคำแปล การอ่านแพ็กกลับ อักษรไทย และระยะฟอนต์ 16 รายการ
ตัวติดตั้งผ่าน 32 ข้อทดสอบจำลอง รวมติดตั้ง อัปเดต คืนภาษาเดิม และกู้คืนเมื่อขาดกลางคัน
ไม่ใช่การรับรองว่าตรวจทุกบรรทัด ทุกฉาก ทุกความละเอียด หรือทุกม็อดร่วมกัน
ข้อความเก็บตกก่อนเผยแพร่ตรวจจากต้นฉบับและแพ็ก แต่ยังไม่ได้เล่นยืนยันทุกคีย์ในเกม
